# ADR-003: Extend CreditsSnapshot with SuperGrok fields

## Status

Accepted

## Date

2026-08-20

## Context

`CreditsSnapshot` has `balance`, `used`, `plan`, `raw_json`, and `err_message`. Grok billing also has period, reset time, prepaid cents, and an optional RPM window. Mapping those into the three existing strings would drop typed JSON and force `/xai-usage` to re-parse display text.

## Decision

Add typed SuperGrok fields to `CreditsSnapshot`: `origin`, `percent` (`?u8`), `period`, `reset_at`, `prepaid_cents`, `rpm_remaining`, and `rpm_limit`. Gateway fetches leave the new fields unset and `origin = gateway`. Grok fetches set `origin = grok` and populate the typed fields, including percent from billing JSON (not parsed from `used`). `deinit` frees any new owned strings. JSON render includes the new fields. Text render delegates to `renderCreditsText` when `origin = grok`. The status-line cache reads `percent` from this snapshot; it must not invent `SG 0%` when percent is null.

## Alternatives Considered

### Alternative 1: Map into existing strings only

- **Description**: `used = "12% weekly"`, `balance = "$2.50"`.
- **Pros**: No contract change.
- **Cons**: Reset and RPM have no home; JSON stays Gateway-shaped.
- **Why rejected**: The user asked to extend the snapshot.

### Alternative 2: Tagged provider result

- **Description**: Return `union(enum) { gateway, grok }` from `CreditsProvider`.
- **Pros**: No field mixing.
- **Cons**: Breaks every `CreditsProvider` caller and WASM stub.
- **Why rejected**: YAGNI. Extending the existing snapshot is enough.

## Consequences

### Positive

- One object feeds CLI text, CLI JSON, TUI notices, and the status-line cache.
- Renderers keep using `grok_billing.Snapshot` internally, then copy into `CreditsSnapshot`.

### Negative

- Gateway JSON grows nullable Grok keys.

### Risks

- Forgetting to free `reset_at` or `period` leaks. Add them to `deinit` in the same change.

## Implementation Notes

Keep `grok_billing.Snapshot` as the parser output. Convert it in `fetchCredits` after a successful billing GET. Do not invent quota from local token counts.
