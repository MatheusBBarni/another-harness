# ADR-001: Cheap HEAD File Read For Branch

## Status

Accepted

## Date

2026-08-20

## Context

The footer paint path must stay cheap. `/statusline branch` needs the current git branch name without spawning `git`, walking the index, or blocking a frame. `src/builtins/context.zig` already reads `.git` and `.git/HEAD` for turn context, including `gitdir:` worktree files, but `collectGitInfo` also loads remotes and worktree state.

Issue 6 requires omitting the branch when the workspace is not a repo or the HEAD is detached with no branch name.

## Decision

Resolve the branch with a cheap filesystem read of `.git/HEAD`, including `gitdir:` worktree files. Parse only `ref: refs/heads/<name>`. Cache the result on App. Never spawn `git`. Omit the segment for missing `.git`, unreadable HEAD, non-branch refs, and detached HEAD.

## Alternatives Considered

### Alternative 1: Spawn git off-paint

- **Description**: Run `git rev-parse --abbrev-ref HEAD` away from paint and cache the result.
- **Pros**: Handles unusual git layouts that a HEAD file read can miss.
- **Cons**: Process spawn, PATH, and timeout complexity on a footer path.
- **Why rejected**: Too expensive and permission-adjacent for an always-visible optional segment.

### Alternative 2: Reuse collectGitInfo as-is

- **Description**: Call the full turn-context git collector and cache that snapshot.
- **Pros**: One shared git implementation.
- **Cons**: Reads remotes, worktree markers, and index metadata the footer does not need.
- **Why rejected**: The extra I/O is unused by cwd/branch and can exceed the footer budget.

## Consequences

### Positive

- Paint stays borrow-only after a cached string is available.
- Non-git and detached workspaces fail closed without user-visible errors.

### Negative

- Unusual git layouts that need `git` to resolve a name will omit the branch.

### Risks

- Worktree `gitdir:` files can point outside the workspace. Mitigation: reuse the existing bounded HEAD read pattern and omit on any I/O or parse failure.

## Implementation Notes

Do not reuse `branchFromHead` as-is. That helper emits `detached:<sha>` for turn context, which the footer must omit.
